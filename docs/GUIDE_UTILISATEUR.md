# Guide utilisateur (aperçu)

## Se connecter
Adresse e-mail + mot de passe (10 caractères minimum, majuscule, minuscule, chiffre, caractère spécial). Si la double authentification est activée, saisir le code à 6 chiffres. Ne partagez jamais votre mot de passe.

## Ce que vous voyez
Le menu n'affiche que les modules autorisés pour votre fonction. Si un module manque, c'est normal : demandez au responsable.

## Travailler sans Internet
L'application continue de fonctionner sur le réseau du poste. Vos saisies sont envoyées automatiquement au retour de la connexion. L'indicateur en haut de l'écran montre l'état de la synchronisation.

## Règles d'or
- Chercher le patient **avant** de créer un dossier (le logiciel signale les doublons probables).
- Pharmacie : le système délivre d'abord les lots qui périment en premier ; un lot périmé n'est jamais délivré.
- Caisse : une erreur ne s'efface pas, elle se corrige par une écriture inverse avec motif.
- Une dépense exige un justificatif et la validation d'une autre personne que le demandeur.
- Déconnectez-vous en quittant le poste.
